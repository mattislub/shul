# AI‑Website Planner (MVP)

## הרצה
pnpm i # או npm i / yarn
pnpm dev # http://localhost:3000

## מה יש כאן
- יצירת תוכנית אתר מלאה ללא קלט (Zero‑Input)
- איתור חוסרים ושאלות ממוקדות בלבד (/api/gaps)
- שיפור סגנון בכל התוכנית בלחיצה (/api/refine)
- יצוא JSON למסירה (/api/export)

## החלפת ה‑Mock במודל אמיתי
- בקובץ `lib/llm.ts` החלף את הפונקציות בקריאות למודל (OpenAI/אחר) עם פרומפטים שהוגדרו.
- מומלץ לשמור לוג של הוראות ושינויים (audit) וולידציה עם Ajv לפני שמירה/ייצוא.
